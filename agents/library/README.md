# Elevare Studio — Pattern Library

Curated, generalized, copy-pasteable assets harvested from finished studio jobs. **Reuse beats rebuild** — before building anything from scratch, check here for the closest starting point, then adapt (each asset notes what it assumes).

This is the studio's compounding asset base (PLAYBOOK "Compounding the studio" → *Harvest reusable assets*). Assets here are **generic** — client names and business logic have been stripped. If you need to add something, generalize it first, dedupe against what exists, and register it in this index with a one-line "when to reach for it."

## Location convention
- `D:\.claude\agents\library\<domain>\<pattern>.md` — one file per reusable recipe.
- Each entry: a titled snippet/recipe, **When to reach for it**, and **Assumes / adapt** notes.
